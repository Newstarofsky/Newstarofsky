### 🛠 กำลังทำอยู่ — ระบบ ERP ที่ใช้งานจริง

เขียนระบบหลังบ้านใหม่ทั้งระบบให้ธุรกิจรับเหมางานระบบ/ซ่อมบำรุงแห่งหนึ่ง
เพื่อมาแทนระบบเดิมที่ใช้งานอยู่ **ตอนนี้อยู่บน production แล้ว** มีช่างลงเวลาเข้า–ออกงาน
เปิดใบงาน และให้ลูกค้าเซ็นรับงานผ่าน LINE ทุกวัน

| | |
|---|---|
| **เทคโนโลยี** | Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · PostgreSQL (Neon) · Vercel · LINE Messaging API + LIFF |
| **ขนาดงาน** | 55 หน้าเว็บ · 26 API routes · ~44,000 บรรทัด · 560 เทสต์ |
| **โจทย์ที่ยากที่สุด** | ระบบใหม่กับระบบเดิมใช้ฐานข้อมูลชุดเดียวกันระหว่างเปลี่ยนผ่าน — ย้ายทีละโมดูลได้โดยข้อมูลไม่หายและไม่ต้องหยุดใช้งาน |

### 🔍 วิธีที่ผมทำงานกับ AI

โค้ดส่วนใหญ่ AI เป็นคนพิมพ์ ผมเป็นคนกำหนดโจทย์ ตรวจ และตัดสินใจ
เพราะระบบที่ผมดูแลมีข้อมูลลูกค้าและเงินเดือนพนักงานจริงอยู่ ถ้าเชื่อโดยไม่ตรวจ
ความเสียหายเกิดกับคนจริง — ห้าด่านนี้คือสิ่งที่โค้ดต้องผ่านก่อนขึ้นใช้งาน

1. **อ่านข้อมูลจริงก่อน ห้ามเดา** — ตารางนั้นมีกี่แถว คอลัมน์ไหนมีค่าจริง ระบบเดิมเขียนอะไรลงไป
   (หลายครั้งข้อมูลจริงล้มสมมติฐานที่ทั้งผมและ AI ตั้งไว้)
2. **ซ้อมคำสั่งที่เขียนฐานข้อมูลในธุรกรรมที่ ROLLBACK** แล้วยืนยันว่าจำนวนแถวทุกตารางเท่าเดิม
3. **ให้ฐานข้อมูลเป็นคนปฏิเสธ** — การอ่านทั้งหมดวิ่งผ่านธุรกรรมแบบอ่านอย่างเดียว
   เผลอเขียนคำสั่งผิดเมื่อไรก็ถูกปฏิเสธเอง ไม่ต้องหวังพึ่งการรีวิวอย่างเดียว
4. **เทสต์ผ่าน + build ผ่าน + เห็นผลบนหน้าจอจริง** — "คอมไพล์ผ่าน" ไม่ได้แปลว่าผู้ใช้กดแล้วได้ผล
5. **ปุ่มที่ทำท่าว่าบันทึกแต่ไม่บันทึก ถือเป็นบั๊ก** — AI ชอบสร้างของที่ "ดูเหมือนทำงาน"
   โมดูลไหนยังบันทึกจริงไม่ได้ ให้ซ่อนไปก่อน ดีกว่าปล่อยให้ผู้ใช้เข้าใจผิด

### 🐞 ตัวอย่างบั๊กที่เจอและแก้จริง

**"ลงชื่อเข้างานได้แต่ออกไม่ได้"** — ช่างแจ้งเข้ามาเอง ดูข้อมูลจริงพบว่าวันนั้นเช็คอิน 9 คน
เช็คเอาต์ 0 คน · สาเหตุคือหน้าจอบนมือถือไม่ได้อ่านสถานะของวันนั้นมาก่อน ปุ่ม "ออกงาน"
จึงไม่เคยขึ้นให้กด · แก้ ทดสอบ และ deploy เฉพาะตัวแก้ภายในชั่วโมงเดียว

**ชั่วโมง OT ที่อนุมัติแล้วถูกล้างทิ้ง** — เจอระหว่างแก้เคสข้างบน: การกดออกงานเขียนทับ
ชั่วโมง OT เป็นศูนย์ทุกครั้ง ซึ่งเป็นข้อมูลที่ใช้จ่ายเงิน

**สูตรคิดช่วงเดือนที่ใช้วันที่ 31** — เดือนที่ไม่มีวันที่ 31 ถูกเลื่อนไปต้นเดือนถัดไป
ทำให้เพดาน OT รายเดือนนับชั่วโมงข้ามเดือนมาด้วย แล้วปฏิเสธคำขอที่พนักงานมีสิทธิ์ขอจริง
